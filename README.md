EVPRIME Backend Automated Tests

This project contains backend test cases and API testing for the EVPrime application.

 Features
- User signup tests
- Login tests
- Positive and negative scenarios
- Validation and error handling checks

 Technologies
- Java
- REST API testing
- Maven

 Test Coverage
- HTTP status codes (200, 201, 422)
- Response validation
- Error messages verification

 Purpose
To test backend functionality and ensure API reliability and correctness.
